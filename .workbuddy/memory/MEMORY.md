# 项目介绍
这是一款由AI自动化驱动的Spine动画编辑器。
本文档只记录用户直接描述的约定，Agent不应擅自编辑。
Agent只产出代码，代码应按模块分类整理好，函数名望文生义，无需文档。
项目是一款工具类产品，所见即所得，以实际功能的表现为准。

# 项目约定

1. **不写文档**。仓库里只有代码：不建 `Doc/`、不建说明文件、不新增 `*.md`、代码里不写注释和 docstring。
   要解释的东西靠命名和结构本身说清。
2. **不写流水账**。`.workbuddy/memory/` 只放本文件，只记约定；不写日记、不记过程、不写「已完成 X」。
3. **不写防御性代码**：不防误操作、不防回归、不做旧格式兼容，输入不对就报错退出。
4. **骨骼只有 int index，全流程没有名字这一层**。
5. **一个步骤一个脚本**，共用逻辑进模块；页面文案全在 `repro/config/copy.json`，`server.py` 不写死。
6. **`input/` 只放用户扔进来的原始素材，`edit/` 只放页面写出来的编辑记录**。
